# Portfólio pessoal - Andressa Ribeiro

Projeto da atividade prática de Fundamentos da Programação Web (UNINTER).

O site apresenta quatro partes: Sobre mim, Formação, Portfólio e Contato. Foi feito com HTML, CSS e JavaScript, sem frameworks.

## Como visualizar

Abra o arquivo `index.html` no navegador.

## Arquivos

- `index.html`: conteúdo e organização da página.
- `estilo.css`: cores, tamanhos e adaptação para celular.
- `script.js`: menu de navegação e validação do formulário.
- `assets/favicon.svg`: ícone da aba do navegador.

## Sobre o formulário

O formulário valida nome, e-mail e mensagem. Ao clicar em enviar, mostra uma confirmação, mas não encaminha nem salva os dados. Ele serve apenas como demonstração acadêmica.
